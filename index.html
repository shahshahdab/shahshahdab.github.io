🚀 What Is fastcampus-jev?

Most AI assistants do two jobs at once: they decide what to do, and then they write the answer. That works fine until the assistant picks the wrong action, or gets tricked into doing something risky.

fastcampus-jev teaches a different split. Jev is a decision-only model — it never writes sentences. You give it a small set of options, and it returns a typed answer plus a confidence score. The language model then writes the words based on that decision.

The tutorial walks through this idea end to end using a pretend online store called Teddy Market. You watch a customer-support assistant decide which tool to use, screen incoming messages for trouble, and pause before doing anything irreversible — all driven by Jev.

✨ What You Get

  • Tool selection. Jev narrows down the possible actions first. The language model only fills in the small details afterwards.
  • Guardrails. Prompt injection, rude language, insults, and personal information are all caught in a single Jev check — even when the bad instructions are hidden inside a tool result.
  • Risky-action gates. Order cancellations and refunds require a confirmation step that asks, "did the user actually request this?" If the answer is unclear, the case is handed to a human.
  • Thirteen notebooks. Bite-sized lessons you can open, read, and run in order.
  • A sample app. A small storefront so you can see the ideas working in a real interface instead of only in code.

🔍 How It Works, in Plain Words

Think of a busy office. There is a manager who makes decisions, and a writer who produces the letters. The manager never writes; the writer never decides. That is the whole idea behind this project.

Jev plays the manager. It is fast, it is limited to the choices you hand it, and it always returns something typed and predictable. The language model plays the writer. It is good with words but not trusted with judgement.

Because the decision step is small and structured, it is easy to test, easy to log, and easy to stop. That is what makes the safety features in this tutorial practical rather than theoretical.
